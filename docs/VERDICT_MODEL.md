# PixelTruth Verdict Model

PixelTruth uses a deterministic aggregation engine (`src/utils/aggregator.js`) to combine multiple diagnostic signals into a structured verdict model.

**Crucially, PixelTruth NEVER adds probabilistic scores together to create a single "AI Probability" score.** Unrelated heuristics (like ELA compression differences and AI Model scores) are fundamentally different signals and cannot be mathematically combined without a validated scientific calibration.

## Signal Types

1. **Cryptographic Provenance**: Ground truth signed by hardware (cameras) or software (Photoshop).
2. **Metadata Indicators**: Plaintext clues left by software (e.g., EXIF Software tags mentioning "Midjourney").
3. **Forensic Signals**: Physical anomalies in the binary or pixel data (ELA, FFT).
4. **Model Signals**: Heuristic probabilities generated by local AI classification models.

## Aggregation Hierarchy

The aggregator evaluates signals in a strict priority order:

1. `VERIFIED_SIGNED_AI_PROVENANCE`
   - Triggered when C2PA explicitly signs an AI-generation or modification action. This is the highest level of certainty.
2. `TRUSTED_PROVENANCE_NO_AI_ASSERTION`
   - Triggered when a trusted hardware manifest (e.g., Sony Camera) signs the image, explicitly confirming it was not synthetically generated.
3. `AI_TOOL_INDICATOR`
   - Triggered when no cryptographic signature exists, but plaintext metadata explicitly names an AI tool.
4. `MULTIPLE_SYNTHETIC_SIGNALS`
   - Triggered when *multiple* independent heuristic engines (e.g., ELA + AI Model) flag anomalies.
5. `INCONCLUSIVE`
   - Triggered when only a *single* diagnostic heuristic flags an anomaly (e.g., only ELA, or only the AI model), which is insufficient to determine origin.
6. `NO_SIGNIFICANT_SIGNAL`
   - Triggered when all enabled checks pass cleanly. (Note: This is never phrased as "Real" or "Not AI", as absence of evidence is not evidence of absence).

## Result Structure

The `aggregateSignals()` function returns a structured object that is consumed directly by the UI:

```javascript
{
  overallAssessment: '...',    // The primary verdict category
  humanReasoning: '...',       // An explicit English explanation of WHY this verdict was reached
  provenance: { ... },         // Raw C2PA data if available
  metadataSignals: [ ... ],    // Array of parsed plaintext metadata clues
  forensicSignals: [ ... ],    // Array of ELA/FFT anomalies
  modelSignals: [ ... ],       // Array of local AI model flags
  limitations: [ ... ]         // Explicit disclaimers about the signals
}
```
