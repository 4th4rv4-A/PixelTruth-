# Privacy Policy & Mechanics

PixelTruth is built on a single, uncompromising principle: **Local-First Privacy**.

## 1. Local Image Processing
When you load an image into PixelTruth, the file is processed entirely by your browser on your device. 
**No image is ever uploaded to a cloud server.**
- Metadata extraction is done locally via JavaScript.
- Cryptographic provenance validation (C2PA) happens locally via a WebAssembly runtime.
- Visual forensic diagnostics (ELA, FFT) are computed on your device.
- Local AI model execution (if enabled) runs in your browser via ONNX Web Runtime.

## 2. No Analytics or Third-Party Tracking
PixelTruth explicitly does not include Google Analytics, Meta Pixel, or any other third-party tracking scripts. 
All assets (including fonts) are self-hosted. When you use PixelTruth, no external service knows what you are doing.

## 3. Local Workspace (IndexedDB)
PixelTruth features an optional "Saved Workspace". 
When you save a forensic case, the data is stored in your browser's local `IndexedDB`.
- **What is stored:** The structured JSON report, image dimensions, and a tiny, highly compressed thumbnail (for the UI).
- **What is NOT stored:** The original, uncompressed, raw binary image file. 
- **Data Extrication:** This data never leaves your device. You can completely wipe this database at any time using the "Clear Local Data" button in the Workspace tab.

## 4. Forensic Report Transparency
The Forensic Reports generated by PixelTruth are deterministically compiled and intentionally do not contain obscure "black-box" magic scores. We explicitly list the limitations of diagnostic heuristics to prevent false accusations.
